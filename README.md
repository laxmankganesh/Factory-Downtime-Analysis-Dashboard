# Factory Downtime Analysis Dashboard

## Overview
This project was completed as part of the **Deloitte Data Analytics Virtual Job Simulation (Forage)**.

The objective was to analyze manufacturing telemetry data, identify downtime patterns, and create an interactive Tableau dashboard to support business decision-making.

---

## Problem Statement
Manufacturing equipment downtime affects production efficiency and operational costs.

The goal was to:
- Identify factories with the highest downtime
- Identify devices contributing to downtime
- Present insights using interactive dashboards
- Support data-driven decision making

---

## Dashboard Highlights
- Factory-wise downtime analysis
- Device-wise downtime analysis
- Interactive Tableau dashboard
- Visual comparison of downtime across locations

---

## Key Insights
- Identified the factory with the highest downtime.
- Identified equipment contributing most to production downtime.
- Used visualization to simplify operational analysis.
